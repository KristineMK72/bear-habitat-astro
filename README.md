# Ursidae Atlas

Astro rebuild of [bear-habitat-3d](https://github.com/KristineMK72/bear-habitat-3d).

The original Next.js site was a thin four-species gallery. This version is a static atlas of all eight living bears: range notes, diet mix figures, typical mass comparison, conservation status, and a MapLibre camera map.

```bash
npm install
npm run dev
```

Deployed as a static Astro app on Vercel.
